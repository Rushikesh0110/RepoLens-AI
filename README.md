# RepoLens AI

An ambitious, local-first AI-powered codebase intelligence platform.

RepoLens AI helps developers understand unfamiliar codebases through
repository analysis, semantic code search, AI-powered question answering,
and evidence-based bug investigation.

## Vision

Build an intelligent developer assistant that understands how a software
repository is structured, how its components interact, and where important
functionality is implemented.

## Core Features

- Local repository ingestion and scanning
- Code structure and symbol extraction
- Repository analytics and visualization
- Semantic code search
- Retrieval-Augmented Generation (RAG)
- Evidence-based codebase question answering
- AI-assisted bug investigation
- Retrieval and answer evaluation

## Technology Stack

- Python
- Streamlit
- FastAPI
- Ollama
- Qwen3 4B
- Python AST
- NumPy and Pandas
- Scikit-learn
- Sentence Transformers
- ChromaDB
- SQLite
- Pytest

## Development Philosophy

- Local-first development
- Privacy-conscious repository processing
- Modular and maintainable architecture
- Evidence-grounded AI responses
- Measurable evaluation and testing

## Project Status

Currently in Milestone 0: Project Foundation.

## Future Goal

Build a complete local AI developer assistant capable of understanding,
searching, explaining, and investigating real-world software repositories.
